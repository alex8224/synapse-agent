# 协作交互原型

在 `web/` 运行 `npm run dev`，打开 `http://localhost:5173/collaboration-prototype.html`。新版入口加载 `Experience.tsx`，复用正式 `index.css` 的主题和控件。点击预填输入框的发送按钮，约 18 秒自动演示联系对方、并行工作、回传和接续。

通过 `+` 或 `@` 选择会话，点击会话引用在右栏预览。侧栏进入对方会话不会中断演示。展开联系记录可关闭自动继续；停止后只接收迟到回复，不自动重启。重置会清空消息和定时任务。

仅模拟登录接口场景，不调用模型、不访问正式会话或存储、不修改项目文件。输入普通消息只得到模拟回复；刷新即重置。独立 HTML 不纳入正式构建。旧 `Prototype.tsx` 不再被入口加载。
